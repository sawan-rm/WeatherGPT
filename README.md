# 🌦️ WeatherGPT

AI-powered conversational weather intelligence platform with agriculture advisory support.

## Tech Stack
- **Backend**: Python + FastAPI
- **Frontend**: Next.js (TypeScript)
- **Database**: PostgreSQL + Redis
- **AI**: Gemini / Groq / Mistral / Ollama
- **Weather**: OpenWeatherMap + Open-Meteo
